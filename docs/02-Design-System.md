# BEL ACADEMY DESIGN SYSTEM SPECIFICATION v1.0

## Purpose

This document defines the visual identity, UI patterns, layout rules, design principles, and component standards for the BEL ACADEMY Showcase Website and Dashboard.

The goal is to ensure design consistency across all pages and create a professional, trustworthy, and modern educational brand experience.

---

# Brand Personality

BEL ACADEMY should feel:

* Professional
* Modern
* Educational
* Trustworthy
* Friendly
* Accessible
* Premium

Users should immediately feel:

"BEL ACADEMY is a serious institution for learning English."

Avoid any appearance that feels outdated, cluttered, or overly corporate.

---

# Visual Direction

Design inspiration:

* Modern education platforms
* SaaS landing pages
* Professional academy websites
* Startup-style interfaces

The design should balance:

Professionalism + Approachability

# Animation Guidelines

Animations should be subtle.

Allowed:

* Fade in
* Hover elevation
* Smooth transitions

Avoid:

* Excessive motion
* Flashy effects
* Distracting animations

---

# Design Goal

The final website should create a strong contrast between the current social-media-based presentation and a professional academy brand.

The owner should immediately recognize the value of having a dedicated digital platform for BEL ACADEMY.
