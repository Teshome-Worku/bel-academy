# BEL ACADEMY SHOWCASE WEBSITE SPECIFICATION (v1.0)

## Project Overview

BEL ACADEMY is an English language training center primarily serving Afaan Oromo speakers. The academy provides both physical and online English language training and currently operates through social media platforms and physical branches.

The purpose of this project is to create a modern showcase website and dashboard prototype that demonstrates how BEL ACADEMY can transform its brand presence and student management process through digital technology.

This showcase is intended for presentation to the BEL ACADEMY owner and is not the final production system.

---

# Project Objectives

The website should:

1. Present BEL ACADEMY as a modern and professional education brand.
2. Improve trust and credibility.
3. Centralize academy information.
4. Demonstrate online student registration.
5. Demonstrate student management capabilities through a dashboard prototype.
6. Showcase future digital transformation possibilities.
