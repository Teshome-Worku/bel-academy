# BEL ACADEMY Showcase Website

A modern showcase website and dashboard prototype designed for BEL ACADEMY, an English language training academy serving Afaan Oromo speakers.

This project demonstrates how BEL ACADEMY can strengthen its digital presence, simplify student registration, and modernize student management through a professional web platform.

---

## Project Purpose

The purpose of this project is to create a high-quality demonstration that showcases:

- Professional academy branding
- Online student registration experience
- Branch visibility
- Program presentation
- Community engagement
- Future student management capabilities

This project is currently a showcase/demo version and is not intended for production use.

---

## Project Goals

- Improve BEL ACADEMY's online presence
- Centralize academy information
- Provide a modern registration experience
- Demonstrate administrative management capabilities
- Create a strong first impression for prospective students
